# topelius-lukukirjat-files

This repository contains backend files for the Finnish edition of Topelius *Luonnonkirja* (1860) and *Maamme kirja* (1878).

Initially, it will only contain files for *Luonnonkirja*. *Maamme kirja* will be migrated here later.



## Content

Short descriptions of the folders in the repository:

### [`documents`](documents/)

Original files for reading texts, comments, variants and editorial texts in XML format. This folder is automatically synced from the SVN server and must not be manually changed. Edit the files in SVN instead.

**NOTE!** File names and folder names in `documents` must not contain Scandinavian or diacritical characters or spaces! It is best to stick to the characters `A-Z`, `a-z`, `0-9`, `-` (hyphen), and `_` (underscore).

### [`md`](md/)

Markdown files for the web page texts about the edition.

### [`toc`](toc/)

JSON files with tables of contents for text collections.

### [`xml`](xml/)

Published XML files. No manual changes should be made to the files in this folder. The files are generated by a publishing script based on the files in [`documents`](documents/) and metadata about the texts in the database.

### [`xsd`](xsd/)

XML Schema-files for validating XML.

### [`xslt`](xslt/)

XSLT-stylesheets that transform XML into other formats, including HTML.

## Oxygen XML Editor Settings

There are some settings you need to change/check in [Oxygen XML Editor](https://www.oxygenxml.com/) after installing the program. Go to *Options* > *Preferences* to open the settings. Then check the following:

1. *Encoding*: For **UTF-8 BOM handling**, select **Don't write**.
2. *Editor* > *Edit Modes* > *Text*: Check **Line wrap** so that the editor displays long lines broken into multiple ones; check **Show line numbers** to enable line numbering in the editor.
3. *Editor* > *Format*: Check **Indent with tabs** (it is best if we all use the same setting for how indentation is marked in XML files; if not with tab characters, spaces will be used, but the formatting of files will become inconsistent if some of us use tabs and others use spaces).
4. *Editor* > *Document Validation*: Check **Enable automatic validation**.

Additionally, the address `raw.githubusercontent.com` must be added as a so-called Trusted Host for Oxygen to read validation schemas stored on GitHub. Do the following:

1. Select *Options* -> *Preferences*.
2. Select *Network Connection Settings* -> *Trusted Hosts*.
3. If the Hosts list already contains the address `raw.githubusercontent.com:443`, edit the address and remove `:443`.
4. If `raw.githubusercontent.com` is not in the list, click *New* and add the address.
